# NJ 2024 Crime Database

**Group Project**

A relational database project analyzing 2024 crime data from New Jersey.

## Overview

This project contains a relational database designed around New Jersey crime data from 2024. The database consists of six interconnected tables:

- Agencies
- Incidents
- Offenses
- Victims
- Offenders
- Arrests

The database contains over 1 million tuples and was designed to support relational queries and analysis.

## Dataset

The data was obtained from the FBI Crime Data Explorer's Crime Incident-Based Data by State.

## Project Components

- SQL queries
- Entity-Relationship (ER) diagram
- Data analysis and reporting
